# Rock Scissors Paper Wind
A simple game in Python. You play against the computer.

## Features

- Play rock, paper, scissors or wind
- Computer chooses randomly
- Custom win goal: choose how many wins/losses to play until
- Counts wins and losses
- Input validation for numbers

## How to run

1. Install Python
2. Run `rock_paper_scissors.py`
3. Type `rock`, `paper`, `scissors` or `wind`
4. Try to win a computer

## Example
```
How many wins/losses will we play until? (number) 2

rock, paper, scissors, wind: rock
Computer chose: scissors
You win!

rock, paper, scissors, wind: paper
Computer chose: scissors
Computer wins!

rock, paper, scissors, wind: wind
Computer chose: paper
You win!

You won the game! Wins: 2, losses: 1
```
