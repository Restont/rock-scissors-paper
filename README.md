# Rock Scissors Paper
A simple game in Python. You play against the computer.

## Features

- Play rock, paper, or scissors
- Computer chooses randomly
- First to 3 wins
- Counts wins and losses
- Type `stop`, `exit`, `quit`, or `end` to quit

## How to run

1. Install Python
2. Run `rock_paper_scissors.py`
3. Type `rock`, `paper`, or `scissors`
4. Try to win 3 times before the computer does

## Example
```
rock, paper, scissors: rock
Computer chose: scissors
You win!
rock, paper, scissors: paper
Computer chose: scissors
Computer wins!
rock, paper, scissors: scissors
Computer chose: scissors
Draw!
rock, paper, scissors: stop
You won the game! Wins: 1, losses: 1
```
